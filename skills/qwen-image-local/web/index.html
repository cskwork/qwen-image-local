Model location & first-time setup

Missing models? In the repository folder, run:

python skills/qwen-image-local/scripts/qwen_local.py install

Then restart this server. To reuse models elsewhere, set QWEN_IMAGE_LOCAL_ROOT before launching.

Initial download: about 11GB. Generation uses local files only.
