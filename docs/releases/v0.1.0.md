# v0.1.0 — Local studio, history, and references

Generate images in a local browser, browse earlier versions, restore a prompt and its settings, and save each new result separately.

## Included

- Windows launcher: double-click `start-web.cmd` after installing Python and the models.
- Prompt controls beside the output, with status, elapsed time and PNG download.
- Previous/Next and thumbnail history, preserving the latest 100 saved studio versions across restarts.
- Optional reference-image attachment or reuse of a generated version as a reference.
- One active generation per model root, including across separate studio processes.

## Reference-image setup

```powershell
python skills/qwen-image-local/scripts/qwen_local.py install-reference
```

This adds a checksummed 1.16GB vision file. Use the same model root as your base installation. Refresh the studio after installation. PNG/JPEG inputs are stored locally; maximum 8MB and 4096px per side.

## Verification and limits

- Text-only GPU generation has been verified on Windows with an RTX 4060 8GB.
- Automated checks cover validation, output preservation, local request protection, history loading, reference routing and cross-process locking.
- **Reference-conditioned GPU output and visual quality are pending user testing.** The attachment/request path is included as experimental; this release does not claim a completed reference-image acceptance test.
- Uploads, generated images, local configuration and model weights are excluded from the release ZIP.

Download the ZIP, extract it, install the models using the README, and start the studio. Existing users can update their checkout and reuse their model directory. The public GitHub Pages site is an introduction; image generation runs on the user's own PC.
